  <files>sections/main-product.liquid, snippets/product-info.liquid</files>
  <action>
Two changes:

1. **Schema setting** (`sections/main-product.liquid`): Insert a new text setting after the `link` URL setting (after line 1758, before the `text` setting at line 1760). Use this exact JSON:

```json
{
  "type": "text",
  "id": "aria_controls",
  "label": "Modal ID (aria-controls)",
  "info": "Enter enquiry-modal to open the enquiry modal. Leave blank to use the link above."
}
```

Use a plain string label (not a `t:` translation key) -- per research, adding locale files is out of scope and the existing schema mixes plain strings elsewhere (e.g. button_group block at line 1784 uses plain `"name": "Button group"`).

2. **Render call** (`snippets/product-info.liquid`): Replace the single render call at lines 513-516 with a conditional branch. When `aria_controls` is set, render without `href` (so button.liquid produces a `<button>` element, not an `<a>`). When `aria_controls` is blank, render with `href` as before. Replace the block starting at line 513:

```liquid
{%- when 'button' -%}
  {%- if block.settings.text != blank -%}
    {%- if block.settings.aria_controls != blank -%}
      {%- render 'button', aria_controls: block.settings.aria_controls, content: block.settings.text, stretch: block.settings.stretch, background: block.settings.background, text_color: block.settings.text_color -%}
    {%- else -%}
      {%- render 'button', href: block.settings.link, content: block.settings.text, stretch: block.settings.stretch, background: block.settings.background, text_color: block.settings.text_color -%}
    {%- endif -%}
  {%- endif -%}
```

CRITICAL: Do NOT pass both `href` and `aria_controls` in the same render call. When `href` is present, button.liquid renders an `<a>` tag which navigates on click, violating TRIG-03.

Do NOT modify `snippets/button.liquid` -- it already supports `aria_controls`.
Do NOT create a new block type -- per user decision, reuse the existing button block.
Do NOT add any JavaScript -- `x-modal` already handles `aria-controls` clicks natively.
