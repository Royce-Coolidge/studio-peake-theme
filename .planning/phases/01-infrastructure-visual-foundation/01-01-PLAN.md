<task type="auto">
  <name>Task 2: Create gradient overlay snippet and add section schema settings</name>
  <files>snippets/sp-gradient-overlay.liquid</files>
  <action>
1. Create `snippets/sp-gradient-overlay.liquid` -- a reusable Liquid snippet that sections render to apply gradient overlay styles. Usage: `{% render 'sp-gradient-overlay', section: section %}`.

   The snippet should:
   - Check `section.settings.sp_enable_gradient` (checkbox, default true)
   - If enabled, output a `<style>` block scoped to `#shopify-section-{{ section.id }}` that:
     a. Sets gradient pseudo-element opacity based on `section.settings.sp_gradient_strength` (range 0-100, default 100), using `divided_by: 100.0` for float division
     b. Neutralises Prestige's built-in overlay on the same element by setting `#shopify-section-{{ section.id }} .content-over-media::before { background: transparent; }` -- this prevents Prestige's single overlay from conflicting with the SP dual gradient
   - If disabled (checkbox unchecked), output nothing

   The snippet ONLY outputs `<style>` -- it does NOT add the `.sp-gradient-overlay` class to any element. Sections are responsible for adding the class to their `.content-over-media` container.

2. Document the section schema settings that sections should add to their schema JSON to use this system. Include as a Liquid comment at the top of the snippet:
   ```
   Required section schema settings:
   { "type": "checkbox", "id": "sp_enable_gradient", "label": "Enable Studio Peake gradient overlay", "default": true }
   { "type": "range", "id": "sp_gradient_strength", "label": "Gradient strength", "min": 0, "max": 100, "step": 5, "unit": "%", "default": 100, "info": "Adjusts the opacity of the gradient overlay" }
   ```

   NOTE: The actual schema additions to individual sections (slideshow, image-with-text-overlay, etc.) will happen when those sections are worked on in later phases or when gradient overlays are applied. This plan creates the infrastructure; section-by-section application comes as each section is customised.
