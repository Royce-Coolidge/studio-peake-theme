  <action>
1. Create `snippets/sp-focal-image.liquid` -- a reusable snippet for rendering images with focal-point cropping. Usage: `{% render 'sp-focal-image', image: section.settings.image, sizes: '100vw', section_id: section.id %}`.

   The snippet should:
   - Accept parameters: `image` (image object), `sizes` (sizes attribute string, default '100vw'), `section_id` (for scoped styles), `aspect_ratio` (optional CSS aspect-ratio override, e.g. '16/9'), `widths` (optional, default '400,600,800,1000,1200,1600,2000,2400,3200')
   - Guard: if `image` is blank, output nothing
   - Output a `<style>` block scoped to `#shopify-section-{{ section_id }}` setting `object-position` from `image.presentation.focal_point` with fallback to `50% 50%`
   - If `aspect_ratio` parameter is provided, set `aspect-ratio` on the container
   - Output a `<div class="sp-focal-image">` wrapping the image rendered via `{{ image | image_url: width: image.width | image_tag: sizes: sizes, widths: widths }}`
   - Ensure `object-fit: cover` is always paired with the `object-position` (handled via CSS class)

2. Create `snippets/sp-adaptive-layout.liquid` -- a utility snippet that detects image proportions and outputs a CSS class modifier string only. Since Liquid `render` is isolated and cannot set variables in the parent scope, the snippet outputs the computed class name as text.

   Create the snippet to output the CSS class name string only:
   ```liquid
   {%- liquid
     assign ratio = image.aspect_ratio | default: 1.0
     if ratio < 0.9
       echo 'sp-adaptive--portrait'
     elsif ratio > 1.2
       echo 'sp-adaptive--landscape'
     else
       echo 'sp-adaptive--square'
     endif
   -%}
   ```

   Sections will use it like: `<div class="sp-adaptive {% render 'sp-adaptive-layout', image: section.settings.image %}">`. This keeps the detection logic DRY across sections.

3. Append to `assets/studio-peake.css` (do NOT overwrite Plan 01 content -- append after the gradient section):

   ```css
   /* === Focal-Point Image Container (VISF-02) === */

   .sp-focal-image {
     position: relative;
     overflow: hidden;
   }

   .sp-focal-image img {
     display: block;
     width: 100%;
     height: 100%;
     object-fit: cover;
     /* object-position set via section-scoped style from sp-focal-image.liquid */
   }

   /* When aspect ratio is set on container */
   .sp-focal-image[style*="aspect-ratio"] img {
     position: absolute;
     inset: 0;
   }

   /* === Adaptive Layout (VISF-03) === */

   .sp-adaptive--portrait .sp-adaptive__text {
     text-align: center;
     padding-inline: var(--spacing, 1.5rem);
   }

   .sp-adaptive--landscape .sp-adaptive__text {
     text-align: start;
     padding-inline-start: var(--spacing, 2rem);
   }

   .sp-adaptive--square .sp-adaptive__text {
     text-align: center;
     max-width: 80%;
     margin-inline: auto;
   }

   /* Responsive: on mobile all adaptive layouts collapse to centred text */
   @media screen and (max-width: 699px) {
     .sp-adaptive .sp-adaptive__text {
       text-align: center;
       padding-inline: var(--spacing, 1rem);
       max-width: 100%;
     }
   }
   ```

IMPORTANT: When appending to studio-peake.css, read the file first to understand its current content from Plan 01, then append the new sections after the existing content. Do not overwrite.
