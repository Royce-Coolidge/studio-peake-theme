Create `sections/product-enquiry-modal.liquid` with the following structure:

1. **x-modal element** with these exact attributes:
   - `id="enquiry-modal"` (hardcoded string, NOT section.id -- MODL-06)
   - `class="enquiry-modal color-scheme color-scheme--{{ section.settings.color_scheme.id }}"`
   - `handle-editor-events` (required for theme editor -- without this, section appears blank in editor)
   - `aria-label="Product Enquiry"`

2. **Light DOM layout** inside the x-modal:
   ```
   <div class="enquiry-modal__layout">
     <div class="enquiry-modal__image-panel" aria-hidden="true">
       {%- comment -%} Phase 3: product image {%- endcomment -%}
     </div>
     <div class="enquiry-modal__form-panel">
       <dialog-close-button class="contents">
         <button type="button" class="enquiry-modal__close tap-area"
                 aria-label="{{ 'general.accessibility.close' | t }}">
           {%- render 'icon' with 'close' -%}
         </button>
       </dialog-close-button>
       {%- comment -%} Phase 2: contact form {%- endcomment -%}
     </div>
   </div>
   ```

3. **Scoped CSS in a style block** (inside the section, before the x-modal element). Scope all rules under `#shopify-section-{{ section.id }}`:

   Shadow DOM overrides (must use `::part()` -- regular CSS cannot penetrate shadow DOM):
   - `x-modal#enquiry-modal::part(overlay)` — background: rgba(0, 0, 0, 0.5)
   - `x-modal#enquiry-modal::part(content)` — width/max-width/height/max-height: 100%, border-radius: 0, display: flex
   - `x-modal#enquiry-modal::part(body)` — padding: 0, flex: 1, overflow: hidden
   - `x-modal#enquiry-modal::part(close-button)` — display: none (hide shadow close button; we use light DOM close button per MODL-04)
   - `x-modal#enquiry-modal::part(header)` — display: none (shadow header adds unwanted space in full-screen mode)

   Light DOM layout:
   - `.enquiry-modal__layout` — display: grid, grid-template-columns: 40fr 60fr, height: 100%, width: 100%
   - `@media screen and (max-width: 749px)` — `.enquiry-modal__layout` grid-template-columns: 1fr, `.enquiry-modal__image-panel` display: none
   - `.enquiry-modal__form-panel` — position: relative, overflow-y: auto
   - `.enquiry-modal__close` — position: absolute, top: var(--spacing-5, 20px), right: var(--spacing-5, 20px), z-index: 1

4. **Schema block** (CRITICAL -- do NOT copy contact.liquid):
   ```json
   {
     "name": "Product Enquiry Modal",
     "class": "shopify-section--enquiry-modal",
     "enabled_on": {
       "groups": ["custom.overlay"]
     },
     "settings": [
       {
         "type": "color_scheme",
         "id": "color_scheme",
         "label": "t:global.colors.scheme",
         "default": "scheme-1"
       }
     ]
   }
   ```
   Use `"enabled_on"` with `"groups": ["custom.overlay"]`. Do NOT use `"disabled_on"` (that is the contact.liquid anti-pattern).
