# External Integrations

**Analysis Date:** 2026-03-16

## APIs & External Services

**Shopify Admin API:**
- Service: Shopify GraphQL Admin API
- What it's used for: Metaobject management and custom field operations
- SDK/Client: Native Liquid/JavaScript access
- Auth: Shopify store credentials (handled by theme upload/CLI)

**Shopify Storefront API:**
- Service: Shopify checkout and cart operations
- What it's used for: Cart management, inventory queries
- SDK/Client: Fetch API to native `/cart/*` endpoints
- Auth: Public access (no auth required, uses session cookies)

**Third-party Media Service:**
- Service: PhotoSwipe gallery library
- What it's used for: Image gallery and lightbox functionality
- SDK/Client: `assets/photoswipe.min.js` (v5.4.4)
- Auth: Not applicable (client-side library)

**QR Code Generation:**
- Service: QRCode.js library
- What it's used for: Gift card QR code rendering
- SDK/Client: `vendor/qrcode.js` (Shopify Asset CDN)
- Auth: Not applicable (client-side library)

## Data Storage

**Databases:**
- Shopify Product Database
  - Connection: Native Shopify Liquid objects (`product`, `collection`, `page` variables)
  - Client: Shopify theme runtime

**Metaobjects:**
- Custom data type: `project` metaobject (defined in `templates/metaobject/project.json`)
  - Fields: Portfolio/project-specific data
  - Used in: Media grid sections (`sp_use_metaobject_gallery` setting in `templates/page.project.json`)
  - Connection: Shopify Metafield API
  - Access: Via Liquid template syntax and GraphQL

**File Storage:**
- Shopify Asset CDN
  - Hosts all theme assets (CSS, JS, fonts, images)
  - URL format: Generated by `asset_url` and `shopify_asset_url` filters

- Shopify Image CDN (Images)
  - Product images: Via `product.featured_image`, `product.images`
  - Section images: Configured through theme editor
  - URL format: Generated by `image_url` filter with responsive parameters

**Caching:**
- Browser-level caching via HTTP cache headers (Shopify managed)
- Service Worker support possible but not implemented
- No explicit caching layer detected

## Authentication & Identity

**Auth Provider:**

**Customer Data:**

## Content Delivery

**CDN:**
- Shopify CDN
  - All asset URLs processed through Shopify's edge network
  - Automatic image optimization and responsive sizing

**Web Fonts:**
- Shopify Font CDN: `fonts.shopifycdn.com`
  - Custom fonts configured in `config/settings_schema.json`:
    - `bricolage_grotesque_n4` (headings, default)
    - `ovo_n4` (body text, default)
    - `instrument_sans_n4`, `nunito_n4` (available presets)

**Image Optimization:**
- Shopify image filter with responsive sizing
  - `image_url: width: <size>` - Responsive image generation
  - Focal point support: `presentation.focal_point` metadata
  - Format negotiation: WebP with fallback
